# 《这是谐音梗》自动解题

用 DeepSeek 视觉模型识图、猜谐音答案，通过本地应用程序接口（API）填入答案、提交、在答对后点击“恭喜通关”并进入下一题。

程序通过 Frida 临时连接 Unity／IL2CPP 游戏进程，直接取得游戏里的题面图片。模型只接收图片、题面文字、分类、字数和答题反馈，不读取题库中的现成答案。不需要截取桌面或移动鼠标，不修改游戏安装文件。游戏仍需运行。

## 使用

免安装桌面版在 `release/这是谐音梗助手.exe`；也可解压 `release/这是谐音梗助手-便携版.zip` 后运行。成品内置运行库，无需安装 Python 或 Node.js。

界面包含“运行控制”和“视觉语言模型（VLM）配置”两个分页，选中的标签向上凸起。配置页只填写接口地址、模型名称和接口密钥。其他模型参数使用默认值，推理模式关闭；导入旧配置也会恢复这些默认值。接口类型根据地址自动适配。“验证接口并读取模型”读取模型列表，不提交答案；“导入已有配置”可以复用本项目已有的 `config.local.json`。

配置保存到可执行文件旁的 `config.local.json`，用于下一次开始解题；发行压缩包不包含个人密钥。“本次运行”使用下拉栏，包含“猜1题”“猜10题”“一直猜”。猜1题在当前关卡答对后停止；猜10题在本次答对10题后停止；两者停留在最后一题通关画面。一直猜持续进入下一题，直到手动停止。每一关均持续尝试到答对，没有每关请求次数上限，游戏 8 次试错耗尽时自动重开本关，并保留已知线索。关闭窗口会停止服务、断开游戏连接。下方为脚本版的使用方法。

1. 在 Steam 启动《这是谐音梗》，进入一题**中文、静态图片、单人题目**。连接后可切换到其他窗口或最小化游戏。
2. 打开 `config.local.json`，在 `api_key` 中填入 DeepSeek 密钥。也可以用环境变量 `DEEPSEEK_API_KEY`。密钥不要发到聊天里。
3. 在本目录的 PowerShell 终端中运行：

   ```powershell
   .\启动服务.ps1
   ```

4. 在另一个终端开始连续解题：

   ```powershell
   .\控制.ps1 -操作 开始 -模式 当前
   .\控制.ps1 -操作 开始 -模式 十题
   .\控制.ps1 -操作 开始 -模式 连续
   .\控制.ps1 -操作 状态
   .\控制.ps1 -操作 停止
   .\控制.ps1 -操作 关闭服务
   ```

首次依赖已在当前工作目录安装。复制到另一台电脑后，先安装 Python 3.12、Node.js，再运行 `安装依赖.ps1`。如果 PowerShell 禁止运行脚本，可以在单个进程中使用 `powershell -ExecutionPolicy Bypass -File .\启动服务.ps1`。

模型默认使用 `deepseek-flash`，接口地址是 `https://api.deepseek.com`。该模型支持原生图片输入，见 [DeepSeek 官方视觉文档](https://api-docs.deepseek.com/guides/vision/)。按用户要求关闭推理模式（`thinking_enabled=false`），每次只返回一个答案，不要求解释，也不返回候选列表。每次猜答案会调用模型接口。

答错时读取答题区每个字、拼音和声调的实际反馈，再传回模型重新猜测。`correct_position` 表示绿色、位置正确；`present_elsewhere` 表示橙色、存在但位置不对；`absent` 表示灰色、答案中没有。汉字和拼音分别判断，不通过截图识别颜色。提交前检查字的位置和游戏拼音字典中的读音，并拒绝已经失败或被拦截的答案。失败历史保存在 `runs/guess-history.json`，重开关卡、重新点击开始、重启助手后均可恢复；通关后清除本关未完成记录。

每次模型请求同时包含两张题图、反馈的中文逐字摘要、结构化排除与位置条件、失败候选和本地拦截原因。汉字、拼音和声调各自说明；绿色拼音的固定位置、橙色拼音禁止的位置也列入结构化条件。本地检查在模型返回后再执行一次。

重试采用“上一轮答案 → 具体纠错”的对话，保留最初的具体拦截原因，重复记录不会把它覆盖成泛化的“不能重复”。旧记录仅剩泛化重复提示时，会根据当前汉字和游戏读音重新检查并恢复具体原因。连续无效返回时自动调整采样温度到 0.7、1.0、1.2，思考保持关闭，每次仍只输出一个答案。声调灰色只描述为本格未命中，避免相同声调的重复反馈产生全局排除矛盾。

字数错误、重复答案和违反反馈分别记录具体原因，被拦截的候选不提交游戏。界面显示本关请求／提交次数，以及模型请求已等待的秒数。单次请求总时限为 45 秒，超时或暂时网络故障会自动重试；点击停止可取消等待中的模型请求。密钥错误、游戏退出或不支持的题型等需要处理的问题仍会显示具体原因。

## 本地接口

默认地址 `http://127.0.0.1:18741`。服务启动后等待开始请求，不会自动消费模型额度。

| 方法 | 路径 | 功能／请求体 |
|---|---|---|
| GET | `/health` | 桥接初始化状态、游戏进程编号（PID）和主循环心跳 |
| GET | `/status` | 当前题号、答题状态及自动解题进度 |
| GET | `/progress` | 自动解题进度；不依赖游戏主线程 |
| GET | `/puzzle` | 可见题面信息和两张图片的内嵌地址（data URL） |
| POST | `/start` | `{"mode":"current"}` 猜1题；`{"mode":"ten"}` 猜10题；`{"mode":"continuous"}` 一直猜 |
| POST | `/stop` | `{}`，停止 |
| POST | `/shutdown` | `{}`，停止并关闭服务、断开游戏连接 |
| POST | `/submit` | `{"level_id":"题目ID","answer":"猜测答案"}`，手动提交 |
| POST | `/next` | `{"level_id":"题目ID"}`，答对后进入下一题 |

手动提交和跳题接口要求自动解题已停止。提交时检查题号，防止把过期答案送进新题。服务只绑定本机回环地址。

## 定位问题

- 不调用模型，只验证接口与题面导出：` .\启动服务.ps1 -Inspect`。导出的图片在 `runs/inspect/`。
- 不连接游戏，单独测试识图：`python badpun.py solve-image --image "题目.png" --length 2`。
- 运行日志在 `runs/*.jsonl`，记录猜测、拦截原因、游戏反馈和用量，不记录密钥或题面图片。
- 初次连接没有主循环心跳：恢复游戏窗口。成功连接后程序设置 `Application.runInBackground=true`；正常退出时恢复原值。
- 游戏退出后需重启本地服务。游戏更新后内部类名／方法可能改变，需要重新适配。

本程序不包含视频题、英文题和多人模式的自动作答流程。当前适配目标为本机安装的 Steam 构建 `25649557`，元数据版本 31。

## 本机验证记录

- 已导出真实游戏题面，游戏实际 Unity 版本为 `2022.3.62f3c1`。
- DeepSeek 实际猜出第 119 题“打印机”，通过游戏正常输入、提交流程判定为 `Win`；随后成功进入第 120 题。
- 已读取答题区“打火机”和“打印机”的逐字、拼音、声调反馈，包含正确与未命中状态。橙色的“存在但位置不对”通过游戏 `Exist` 枚举直接映射，不依赖颜色截图。
- 游戏最小化、失去焦点时，主循环仍有心跳，能导出两张 `588×400` 题面图片。
- 8 项针对性流程测试覆盖错误后重试、无效字数重试、停止、过期题目、提交确认和橙色反馈传递。

尚未统计大量关卡的准确率；持续尝试不保证模型能解出每道题。三种模式、猜10题到数停止、超过八次请求继续、失败重开保留提示、超时和停止取消已做针对性流程验证。已截取测试中的实际请求，验证图片、颜色与位置提示、本地拦截原因同时传给模型。游戏读音查询和模型仅返回一个答案已实机验证，未故意耗尽游戏尝试来做失败重开实机回归。

## 重新打包

构建工具是 PyInstaller 6.22.3。将其安装到 `.build-deps` 后运行 `python build_app.py`，生成单文件程序和便携压缩包。`python build_app.py --folder` 生成可调试的目录预览包。

本机 360 隔离了 PyInstaller 的 `runw.exe` 启动器；下载发行包的哈希与 PyPI 记录一致，包内该文件与安装记录一致。旧版曾使用控制台启动器加自动隐藏，在部分 Windows 终端配置下仍会出现终端窗口。当前使用 `--windowed` 构建真正的窗口程序，启动时不创建终端。本机普通窗口启动器缺失时使用已安装的官方 `runw_d.exe` 窗口诊断版本；诊断信息通过 Windows 调试输出发送，不创建终端，不恢复隔离文件或更改杀毒软件设置。若两个窗口启动器均缺失，构建明确报错。

桌面模块已验证配置保存／导入所使用的读写流程、下一次运行应用新配置、界面连接游戏和退出清理。免安装成品另行验证两个分页、配置读写及内置依赖资源。

“本次运行”的下拉栏在可用状态使用白色背景；运行或操作暂时锁定时才呈灰色。第135题重复问题已验证原日志中连续15次返回同一候选；调整策略后单次模型实测返回了不同候选，但仍违反灰字条件，未提交游戏，尚未解出本题。
