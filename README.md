# BadPunPC_Assistant

游戏商店：[《这是谐音梗》Steam 商店](https://store.steampowered.com/app/4164310/_/)

《这是谐音梗》Steam 电脑版自动解题助手。通过视觉语言模型（VLM）识别题图、猜测谐音答案，自动填写、提交并进入下一题。

## 功能

- 自动读取题目，并结合汉字和拼音提示继续猜测。
- 每关持续尝试到答对，游戏尝试次数耗尽后自动重开本关并保留线索。
- 支持 DeepSeek、小米 MiMo，以及其他兼容图片输入的模型接口。
- 可选择思考强度，随时停止自动解题。
- 连接后可最小化游戏，不占用鼠标和键盘。

| 运行模式 | 行为 |
|---|---|
| 猜1题 | 解出当前关卡后停止 |
| 猜10题 | 连续解出10个关卡后停止 |
| 一直猜 | 持续解题，直到手动停止 |

“猜1题”和“猜10题”完成后会停留在最后一题的通关画面。

## 下载与安装

从[最新发行版（Release）](https://github.com/DeianHsu/BadPunPC_Assistant/releases/latest)下载 [BadPunPC_Assistant.exe](https://github.com/DeianHsu/BadPunPC_Assistant/releases/latest/download/BadPunPC_Assistant.exe)。

这是 Windows 64位单文件免安装程序。放入自己可写的文件夹后直接双击运行，无需解压，也无需另装 Python 或 Node.js。

使用前需要准备游戏，以及支持图片输入的模型接口和自己的接口密钥。模型调用会消耗对应服务的额度。

## 开始使用

1. 在 Steam 启动《这是谐音梗》，进入中文静态图片的单人关卡。
2. 双击 `BadPunPC_Assistant.exe`。
3. 打开“视觉语言模型（VLM）配置”，填写接口地址、模型名称和接口密钥，选择思考强度后点击“保存配置”。
4. 回到“运行控制”，点击“连接游戏”。
5. 选择“猜1题”“猜10题”或“一直猜”，点击“开始自动解题”。
6. 需要结束时点击“停止”。退出助手会断开游戏连接。

连接成功后可以最小化游戏，但游戏需保持运行。

## 模型配置

| 服务 | 接口地址 | 模型名称 |
|---|---|---|
| DeepSeek（默认） | `https://api.deepseek.com` | `deepseek-flash` |
| 小米 MiMo | `https://api.xiaomimimo.com/v1` | `mimo-v2.6-pro` |

接口密钥填写对应服务商提供的密钥。MiMo 上述地址适用于小米官方按量计费密钥；其他平台提供的密钥应搭配该平台的接口地址和模型名称。

接口地址不要附加 `/chat/completions`。其他模型接口需兼容聊天补全（Chat Completions）并支持图片输入。

- 思考强度默认“高”。DeepSeek 可选“关闭”“低”“高”“最高”。
- MiMo 仅区分思考开启与关闭；选择“低”“高”“最高”都会开启思考。
- “验证接口并读取模型”可读取服务提供的模型列表，也可手动填写模型名称。
- “导入已有配置”可复用之前的配置文件。

配置保存在程序同目录的 `config.local.json`，保存后在下一次开始解题时生效。

## 升级与问题排查

升级时先关闭旧程序，再替换 `BadPunPC_Assistant.exe`。保留同目录的 `config.local.json` 和 `runs` 文件夹，即可继续使用原配置与答题历史。

如果无法连接游戏，确认游戏仍在运行，并已进入单人图片关卡。如果模型请求报错，检查接口地址、模型名称、密钥和服务额度，确认所选模型支持图片输入。

运行控制页会显示当前状态和错误信息；可点击“打开日志目录”查看详细记录。

## 工作原理与技术栈

助手直接读取游戏当前可见的题图、分类、字数和答题提示，将题图和已知条件交给视觉模型推断答案，再调用游戏的正常输入、提交和下一题流程。题图来自游戏，因此无需截取桌面或模拟鼠标点击。

| 技术 | 用途 |
|---|---|
| Python、图形界面工具包 Tkinter／Tcl/Tk | 桌面界面与运行控制 |
| Frida、frida-il2cpp-bridge | 读取运行中的游戏题目并提交答案 |
| Pillow | 处理题图 |
| HTTPX | 连接模型服务 |
| PyInstaller | 生成免安装程序 |

## 适用范围

当前支持 Windows 64位系统上的《这是谐音梗》Steam 客户端，以及中文静态图片的单人关卡。游戏更新后可能需要更新助手以适配。

解题效果取决于所用模型；模型可能答错或反复尝试，持续运行也不保证解出所有题目。可随时点击“停止”。
